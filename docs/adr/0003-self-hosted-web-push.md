# Push uses standard Web Push with server-held VAPID keys

Push is sent with the standard Web Push protocol and VAPID authentication, straight from the API to each browser's own push service (Apple, Google, Mozilla). There is no third-party notification service such as Firebase Cloud Messaging or OneSignal. That keeps Homebase self-contained, with no external account, SDK or vendor data flow. The VAPID key pair is generated by the API on first start and stored in PostgreSQL, not supplied through environment variables. It is backed up with the Push Subscriptions it signs for, and it can't be accidentally changed in config. Losing or rotating it invalidates every Push Subscription.
